# Shared all-level accuracy certificate

This is an artifact-only quantifier repair for the existing line-family API under the exact frozen C-infinity overlay. It does not change a canonical owner, audit, gate, or interpretation, and does not resolve the other general-method, admission, geometry or stability-scope findings.

`Certificate family q p L` has no realization or executed cell parameter. It contains one constant C, its nonnegativity proof, one threshold N, eventual admission of all exact projected inputs, and the complete perturbed-input estimate for every level n at or above N. Thus C and N cannot be selected solely to avoid the level of a particular execution.

`certificate_exists` obtains p and L from the existing uniform `perturbed_accuracy` theorem before considering a reference q. For each genuine smooth reference, it combines the perturbation threshold with the existing exact-projection admission threshold using their maximum. That same resulting threshold and constant belong to a single certificate with the all-level proof. `Certificate.projected_input_exists` constructs the exact cell-average array and proves it admitted beyond this threshold, so the certificate is not an implication over an empty projected-input domain.

`Certificate.executed_bound` takes this already chosen certificate first. It then applies to arbitrary later physical data, line coordinates, family indexing, compatible realization and selected cell. An explicit equality identifies the cell's selected family with the certificate's family, and the caller must prove the already fixed threshold is no greater than the actual selected level. The proof uses `advance_eq`, `extract_error_le`, actual active-cell membership, actual duration equality and the certificate's all-level estimate. It cannot choose a new threshold after seeing the cell. Below the threshold, no higher-order estimate is asserted; exact numerical execution remains a separate existing result.

The scalar CFL-one family is a concrete instance for every genuine C-infinity local reference. The known nonconstant smooth profile also inhabits this domain. Nonconstancy is already proved by `CFLUnitShift.smoothProfile_nonconstant`; it is not an arbitrary eligible-reference predicate. The new witness asserts the stored uniform certificate, without falsely assigning explicit values to rates chosen from an existential proof. The old checked CFL-one family is reused, not reconstructed.

## Reuse and isolation

The three proof producers reused directly are `LineFamily.HasControlledHighResolution.perturbed_accuracy`, `LineCoordinates.extract_error_le`, and `LineRealization.advance_eq`. The estimates module must be imported to obtain `extract_error_le`; its old fixed-level `smooth_accuracy` declaration is present in the imported environment but is neither invoked nor used as a proof dependency. Native `getUsedConstantsAsSet` guards inspect the new existence/execution proofs and those three reused producers and reject that old declaration as an immediate dependency. This guard is deliberately described as an immediate-dependency check, not a claim of complete transitive proof normalization.

The native runner launches a fresh native `lake env` Python child, prepends the immutable `dim-five-owner-overlay/overlay/lib03` to its actual LEAN_PATH, verifies the frozen overlay module map and unchanged-copy hashes, and records actual `lean --deps` results. Both direct project imports resolve to the overlay. `cinfty_definition` is an `Iff.rfl` guard against accidentally loading the original analytic outer-top definition: it explicitly requires `((⊤ : ℕ∞) : WithTop ℕ∞)`. The native command uses only the frozen existing overlay outputs and writes no compiled library artifact.

The fixed coefficient `dt ≤ mesh` limitation of the preceding admission slice is recorded separately in `SCOPE-LIMIT.md`, without modifying that frozen packet. Future full quality still needs appropriately scaled/horizon-bounded actual step domains, independent physical projection and nonsmooth/smooth admission coverage, and separation of conditional stability from the literal high-resolution convention.
