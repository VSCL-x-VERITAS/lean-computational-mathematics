# Interval-line quality repair proposal

This is the explicitly bounded one-dimensional interval branch. Root separately owns the general measured PhysicalRefinement interface. This file does not claim that a physical volume is a spatial width, that every logical grid has a common-area interval realization, or that this alone closes the Chapter 1 source row.

`Geometry` fixes one physical flux law, a nonempty state set, one closed physical interval, one positive horizon and a fixed target interval across all refinements. The actual interval grids, finite input/active windows, their physical containment and fixed target coverage are retained. The mesh equals the largest actual input-cell width and tends to zero; there is no minimum-width comparability condition. Each input cell, including supplied boundary data, has real interval geometry.

`Method` is a refining interval-method family, not a claim that every standalone single-grid method admits refinement certification. Its numerical flux accepts the actual level, positive time-step argument and full input array, and its locality covers the complete used finite stencil. Admission depends on level, dt and input. Every physical-state input has some positive admitted dt. No coefficient-one `dt ≤ mesh`, method-independent CFL, uniform step for all arrays, or downward-closed step interval is asserted. This removes the diagnosed unit-dependent limitation of the preceding frozen slice without editing it.

`CoreQuality` has two fields: smooth order greater than one and quantitative oscillation control. It does not contain pairwise perturbation stability. For every genuine C-infinity reference satisfying the actual spatial conservation law and state domain on the closed physical box, one `SmoothCertificate` stores C,N and its all-level statements. Beyond N, every exact projected input has a positive admitted step within the fixed horizon. The estimate then applies to every actually admitted positive projected-input step within that horizon, using C*dt*mesh^p. Thus neither an empty smooth admission domain nor choosing N after one execution can supply an apparent order claim. Physical input state coverage and exact projected-input admission are separate, since averages need not preserve a nonconvex state set.

Oscillation control covers every positive admitted input/step with a uniform multiplicative rate and a vanishing additive rate. Because physical two-state arrays have positive-step availability, the statement cannot evade all discontinuity data by an arbitrary empty admission predicate. It does not assert that every chosen positive step is admissible, that availability supplies arbitrarily small steps for every nonsmooth datum, or that an available step meets every later comparison requirement.

`SameStepStability` is an independent optional analysis predicate. `SmoothCertificate.perturbed_at` derives the perturbed error bound using the SAME stored C,N and the SAME actual dt for both inputs. Admission of both the projected and actual input at that dt is explicit; existence of some other projected dt does not imply it. This is an all-level local truncation certificate and conditional perturbation result, not a convergence theorem or a higher temporal order claim for Lie splitting.
