# Additive capacity-method boundary replacement

`LineCoordinates.withGhost coord newGhost` replaces only the numerical ghost function. All five coordinate/lookup functions are unchanged, the existing lookup soundness/coverage proofs are reused, replacing a ghost function twice retains the last one, and replacing it by the original ghost returns the original coordinates. The actual physical data, cell regions, cell means, face measures, and face fluxes are not arguments to this replacement and remain unchanged.

`CapacityCoordinate.Method.withGhost method newGhost` returns a method on the new coordinate type. That type is nominally different, so the four incidence proofs are reconstructed using the unchanged coordinate projections. The numerical-flux function and admission function are literally retained. There is no claim that the two nominal method types are definitionally equal.

`capacity_withGhost` proves the exact capacity function is unchanged at every index because lookup is unchanged. `advance_withGhost_eq` identifies the executed physical update with the original capacity/flux line formula applied to the **newly extracted** array. It does not claim that changing boundary inputs leaves the numerical update unchanged. `projection_withGhost` proves actual cell indices still extract the original physical cell means, for any new ghost function.

`extract_withGhost_error_le_max` separates actual-cell error from ghost error. For actual cells the original array bound applies; only missing-lookup positions require a bound on the two ghost functions. The resulting line-array error is at most `max E G`. `coordinate_stability_withGhost` then applies the frozen method's separate same-time-step stability property, with both actual extracted arrays admitted at that same time step, giving physical output error at most `A * max E G`. Nonnegativity of the maximum follows from the actual cell error bound and the partition's nonempty cell type; no unnecessary nonnegativity assumption on a vacuous ghost bound is added.

The generic estimate uses a whole-line error bound, matching the already frozen `Method.StableAt` interface. It is a sufficient bound, not a claim that every method needs infinitely many physical ghost cells. A later finite-stencil stability interface may restrict the compared numerical ghost positions explicitly. These lemmas permit reference-dependent measured boundary projections; they do not construct boundary regions, assert their integrability or coverage, or infer that arbitrary numerical ghost values are physical averages. Root's refinement/reference interface owns those hypotheses.

Reuse: the scoped project search found `LineCoordinates.extract_error_le`, which covers the same fixed ghost on both sides. That theorem cannot directly compare distinct ghost functions, so the new extraction proof repeats only the two-way lookup case split with explicit ghost error. All update and projection equalities reuse the frozen capacity realization methods. The physical stability result reuses its supplied line stability; no new norm recurrence, PDE proof, flux approximation, or quality predicate is introduced.
