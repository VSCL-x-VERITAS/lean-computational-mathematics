# Remaining quality-family obligations

This is a design boundary recorded after the separately frozen admission review. The current native slice proves physical jump coverage, not these further properties.

1. Physical-state input availability is insufficient for smooth projected means on a nonconvex state domain. A complete quality family must separately guarantee eventual positive-step availability for every exact projection of each genuine eligible smooth physical reference. The definition of eligible reference must retain the actual equation and regularity, not an arbitrary possibly empty predicate.
2. For each family/reference, select its uniform constants C and threshold N before the arbitrary refinement level. Beyond N, exact projected inputs must have meaningful positive admitted steps, and the order estimate must cover all their actual admitted time steps in the stated scope. Do not claim order from a conditional over an empty step domain or from choosing N after fixing one executed level.
3. Constants are independent of level and actual admitted dt. The defect C*dt*mesh^p is a per-unit-time truncation estimate. Actual global convergence requires further stability/comparison assumptions; the dimensional Lie composite is not asserted to have order greater than one merely because its constituents do.
4. Keep order/oscillation separate from perturbation stability. Compare both inputs at the same supplied admitted dt. Inputwise existence does not prove a common dt for two different inputs, downward closure of admission, or an interval of available steps.
5. The finite logical operator must use the same positive measured physical capacities and shared integrated fluxes as the actual coordinate update. Exact physical projection is mass divided by that same capacity. Root's frozen PhysicalCapacityBridge proves the active-cell projection/operator correspondence; it does not establish quality for dummy missing-lookup capacity 1 or accuracy of supplied ghost projections.
6. Refinement mesh must describe genuine supplied spatial geometry, including any boundary cells used in a stencil. Volume units or an artificial ghost capacity are not a spatial mesh. This slice uses the exact maximum of real supplied interval-cell widths. A future general physical geometry class requires its own correctly dimensioned refinement data and fixed-region coverage.
